Deskripsi Kegiatan:
Pada praktikum Modul 1 ini, telah dilakukan konfigurasi dan pengujian lingkungan kerja MySQL/MariaDB menggunakan XAMPP CLI dan phpMyAdmin, meliputi:

1. Akses dan Autentikasi CLI:
   - Login ke server MariaDB menggunakan Command Line Interface XAMPP dengan akun root:
     `mysql -u root -p`
   - Verifikasi versi MariaDB (10.4.32-MariaDB) dan identitas user aktif (`root@localhost`) menggunakan query:
     `SELECT VERSION(), CURRENT_USER();`

2. Pengelolaan Database, User, dan Hak Akses (Privileges):
   - Pembuatan database baru (`database_097`).
   - Pembuatan user baru (`akun_097`@'localhost') dengan password terenskripsi.
   - Pemberian hak akses penuh (GRANT ALL PRIVILEGES) pada database `database_097` kepada user `akun_097`.
   - Menampilkan daftar database aktif menggunakan perintah `SHOW DATABASES;`.

3. Pengujian via phpMyAdmin:
   - Akses antarmuka phpMyAdmin localhost (`http://localhost/phpmyadmin`).
   - Pengujian login dan verifikasi struktur database secara visual.

4. Troubleshooting & Maintenance:
   - Penanganan error "MySQL shutdown unexpectedly" akibat file log sementara/crash.
   - Prosedur backup dan pemulihan folder `data` MySQL (`C:\xampp\mysql\data\`).
   - Ekspor struktur dan data ke file `.sql` untuk keperluan version control di GitHub.
